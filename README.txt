FERIA VIVA - PROYECTO WEB ACTUALIZADO

CONTENIDO
- index.html: página principal con seis rubros, galería, video y una sección final visible con el prompt original utilizado para crear el logotipo de Feria Viva.
- paginas/: páginas individuales con fotografías y preguntas con sus respuestas.
- css/estilos.css: estilos adaptables a móvil y computadora.
- js/script.js: navegación y funciones generales de la página.
- img/: fotografías y logotipos SVG.
- video/recorrido-feria.mp4: video incluido en el material de la feria.

PREGUNTAS Y RESPUESTAS
Las secciones por rubro son informativas: muestran cada pregunta junto a su respuesta, sin opciones, formularios, puntuación ni corrección automática. Como no se proporcionó un registro escrito de entrevistas, algunas respuestas se redactaron como respuestas orientativas relacionadas con los rubros; no deben presentarse como citas textuales reales de los participantes.

PROMPT DEL LOGOTIPO
Diseña un logotipo vectorial profesional para una feria de emprendimientos llamada “Feria Viva”. Debe transmitir creatividad, comunidad, talento local y crecimiento. Utiliza un símbolo floral/estelar sencillo pero distintivo, formas limpias, buena legibilidad y una composición equilibrada. Paleta cálida con rosa coral, crema y amarillo dorado, acompañada de tonos oscuros para el contraste. Estilo contemporáneo, amable y elegante, apropiado para una feria académica de emprendimientos. El logotipo debe funcionar en tamaños pequeños y grandes, tener fondo transparente, evitar detalles excesivos y no incluir texto adicional aparte del nombre “Feria Viva”. Entregar como gráfico vectorial SVG.

CÓMO ABRIR
1. Descomprime el ZIP completo en una carpeta.
2. Abre index.html con Chrome o Firefox.
3. Para editar, abre la carpeta feria en Visual Studio Code.

NOTAS
- Los rubros se organizaron según lo visible en las fotografías y el video entregados.
- Las respuestas que no provienen de notas de entrevista se presentan como orientativas, no como testimonios verificados.
- El video se conserva localmente y no requiere conexión a YouTube.
